# 需求调研

## 提问规则

先提取，再补问。已有大纲可以说明主题和章节，但通常不能可靠推断目标、听众及演讲时长。
把字段标为“用户明确 / 材料提取 / 默认 / AI 建议 / 待补充”，不要把猜测当成用户要求。

| 字段 | 要求 | 选项或默认值 |
|---|---|---|
| 主题 | 必填 | 无默认值 |
| 使用场景 | 必填，有默认值 | 方案汇报（默认）、工作汇报、客户交流、演讲、培训、其他 |
| 是否必须使用公司模板 | 必填，有默认值 | 是（默认）/ 否；本项目默认模板：中国电子云 |
| 内容偏好 | 必选，有默认值 | 复杂豪华（默认）/ 专业简洁 |
| 输出格式 | 必选，受模板约束 | 公司模板：固定可编辑 PPTX；非公司模板：可编辑 PPTX（默认）/ HTML |
| 视觉风格与配色 | 按需提取或补问 | 与复杂/简洁的密度偏好分开记录；非公司模板 HTML 据此判断是否走 guizang |
| 目标 | 必填 | 希望听众听完理解什么、认可什么、决定什么或采取什么行动 |
| 听众 | 必填 | 身份、关注点、主题熟悉程度；只补问影响策划的部分 |
| 时长 | 必填 | 正数，单位分钟；必要时明确是否包含问答 |
| 目标页数 | 选填 | 未指定则 AI 按内容、时长建议；明确总页数是否包含封面及章节页 |
| 背景及注意事项 | 选填 | 业务背景、必讲/禁讲内容、敏感信息、口径、日期、语言、品牌要求 |

“必填且有默认值”表示必须形成明确记录，可以使用已展示的默认值。无需逐字段确认；需求补齐后，前台展示完整需求调研内容，并一次确认本阶段文档后再保存。
用户希望一次性填写时，用下面的短表单；如果已有信息则预填，并将 HTML 选项只展示给非公司模板用户。

```text
主题：
使用场景：方案汇报 / 工作汇报 / 客户交流 / 演讲 / 培训 / 其他（默认：方案汇报）
必须使用公司模板：是 / 否（默认：是，中国电子云）
内容偏好：复杂豪华 / 专业简洁（默认：复杂豪华）
输出格式：[公司模板固定为可编辑 PPTX；选择非公司模板后可选 PPTX / HTML]
视觉风格与配色：有指定则填写；HTML 如希望杂志风或设计感请注明
希望达成的目标：
听众：
时长：__ 分钟
目标页数：可留空，由 AI 建议
背景及注意事项：可留空
```

附加信息按需获取，不增加一串无关必填项：

- 已有大纲制作：请用户提供粘贴文本或文件路径；支持的文件类型由当前读取工具决定。
- 需要事实、指标、案例时：询问现有材料和可引用来源；缺失的数据不得编造。
- 非公司模板 PPTX：从目标和背景识别商业 / 企业业务或个人学习研究；不明时补问一次。
- 非公司模板 HTML：明确要求杂志风/杂志感/设计感时选择 guizang，其他选 html-ppt；否定、仅举例或文档正文中的同名词不算风格要求。
- guizang：已有明确“杂志风”要求可记录为电子杂志 A；明确“瑞士风”且已选 guizang 则记录为 B；仅说“设计感”且 A/B 不明确时，一次推荐并询问 A/B 与主题色，复用其他已知信息。用户明确指定 guizang 或瑞士 HTML 风格时也可直接走该路径。
- 用户未指定 guizang 配色时使用其所选主题，不把 html-ppt 分支的编排层默认主蓝 #0058FF 强加给它；明确指定的颜色、图片及截图处理要求须原样交接。
- 用户说必须使用“另一家公司模板”时，先索取指定模板，不能擅自套中国电子云。
- 目标时长与页数明显冲突时，解释节奏影响，提出推荐调整，请用户决定。
- 缺少补充信息时可继续前台整理和补问，不能为了归档而先写未获确认的需求 MD。关键必填项补齐、完整需求前台展示且用户确认后，才保存并进入下一阶段。

## 需求确认与落盘

按照下方模板在对话中展示完整需求内容，包括来源、默认值、已知冲突、拟保存目录和本阶段执行记录。
先问“以上需求是否确认？确认后保存 `需求调研.md`，再进入{思路对齐/已有大纲检查}”。用户确认后落盘并告知路径。
用户直接给了完整需求也不代表已确认 AI 整理的未展示内容；已在前台展示并明确批准的同一版本可复用确认，无需重问。
确认记录可在落盘时补入实际确认时间和原话。默认值、推断及资料提取须在确认前就对用户可见。
